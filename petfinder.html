Aplicativo Mobile

PetFinder

Aplicativo desenvolvido para ajudar pessoas a encontrar seus pets perdidos, com sistema de geolocalização e notificações em tempo real.

Android Java Firebase Google Maps API

Galeria do Projeto

Sobre o Projeto

O PetFinder é uma solução mobile desenvolvida para Android que conecta pessoas que perderam seus pets com aqueles que os encontraram. O aplicativo utiliza tecnologias modernas para oferecer uma experiência completa e eficiente.

Com integração ao Firebase para autenticação e banco de dados em tempo real, e Google Maps API para geolocalização precisa, o PetFinder facilita o reencontro entre pets e seus donos.

Funcionalidades Principais

  • Cadastro de pets perdidos com fotos e informações detalhadas
  • Geolocalização em tempo real usando Google Maps API
  • Sistema de notificações push para alertas de pets próximos
  • Chat integrado para comunicação entre usuários
  • Filtros avançados de busca por raça, cor, tamanho e localização
  • Perfis de usuários com histórico de pets cadastrados

Tecnologias Utilizadas

Android

Desenvolvimento nativo para Android usando Java

Firebase

Backend como serviço para autenticação, banco de dados e notificações

Google Maps API

Integração com mapas para geolocalização e visualização de áreas

Material Design

Interface seguindo as diretrizes do Material Design do Google

Desafios e Soluções

Um dos principais desafios foi implementar a geolocalização em tempo real de forma eficiente, garantindo que as notificações fossem enviadas apenas para usuários próximos. A solução foi utilizar Firebase Cloud Functions para processar as localizações e enviar notificações apenas quando necessário.
