Aplicativo Mobile/Automação & IA

AcquaGyn

Sistema "estilo Waze" para monitoramento de alagamentos em Goiânia. Utiliza Web Scraping para coleta de dados meteorológicos e IA para mapear áreas de risco em tempo real.

Projeto desenvolvido para o Code Craft da PUC Goiás — Medalha de Prata 🥈

Python Web Scraping PyTorch/Pydantic Machine Learning

Galeria do Projeto

Sobre o Projeto

O AcquaGyn é uma solução inovadora que combina automação, web scraping e inteligência artificial para monitorar e prever alagamentos na cidade de Goiânia. Inspirado no conceito do Waze, o sistema permite que usuários visualizem áreas de risco em tempo real e recebam alertas preventivos.

O projeto foi desenvolvido para o Code Craft da PUC Goiás e recebeu medalha de prata na competição, reconhecendo a qualidade da solução e a aplicação de tecnologias como Web Scraping e IA no contexto de mobilidade urbana e prevenção de desastres.

Utilizando técnicas avançadas de web scraping para coletar dados meteorológicos de múltiplas fontes e modelos de machine learning treinados com PyTorch, o sistema consegue mapear e prever áreas propensas a alagamentos com alta precisão.

Funcionalidades Principais

  • Web scraping automatizado de dados meteorológicos em tempo real
  • Modelo de IA para previsão de áreas de risco de alagamento
  • Mapa interativo mostrando zonas de risco em tempo real
  • Sistema de alertas push para usuários em áreas afetadas
  • Dashboard com visualização de dados históricos e tendências
  • API REST para integração com outros sistemas

Tecnologias Utilizadas

Python

Linguagem principal para desenvolvimento do sistema

Web Scraping

Coleta automatizada de dados meteorológicos de múltiplas fontes

PyTorch

Framework de deep learning para modelos preditivos

Pydantic

Validação e parsing de dados com type hints

Desafios e Soluções

Um dos principais desafios foi lidar com a variabilidade e qualidade dos dados coletados via web scraping. A solução envolveu a implementação de múltiplos scrapers com fallback automático e validação rigorosa usando Pydantic para garantir a qualidade dos dados antes do processamento pela IA.

O treinamento do modelo de machine learning também foi desafiador, exigindo coleta e limpeza de dados históricos extensos. A solução foi criar um pipeline automatizado de coleta e processamento de dados que roda continuamente, melhorando constantemente a precisão do modelo.
